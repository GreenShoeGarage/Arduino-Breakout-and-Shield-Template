# UNO R4 Minima SWD riser · Rev B

Order one riser for each Minima carrier. Select the two-layer 1.6 mm PCB option. Riser J1 is a bottom-mounted 2 × 5 Harwin socket. Two soldered strips connect riser J2/J3 to carrier J19/J20. Install at a 4.60 mm board-to-board air gap. The pin-1 pad is square. Shield pad and terminal numbers are listed independently in the continuity table.
